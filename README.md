# babyready-site

The BabyReady free kit builder: a static, mobile-first site for GitHub Pages. No server; all logic runs in the browser and answers stay in the visitor's localStorage. Only the email address leaves the device (to Kit).

| File | What it is |
| --- | --- |
| `index.html` | The 5 builder screens (start/ZIP, household, baby feeding, preview + email gate, full list with thank-you) |
| `privacy.html` | Privacy policy |
| `assets/config.js` | Kit form ID, Meta pixel ID, RD sign-off switch, contact details |
| `assets/rules-data.js` | Lite rows of the rules table (generated by `tools/build_rules.py`; don't edit by hand) |
| `assets/rules.js` | Amount formulas and sections for each Lite row (**unreviewed** until Josh signs off) |
| `assets/app.js` | Builder logic, Kit sign-up, print |
| `assets/pixel.js` | Meta pixel: PageView, plus Lead after a successful sign-up. Automatic events off |

## Before launch
1. Josh signs off the amounts; set `rdSignedOff: true` (adds "Reviewed by Joshua West, RD" and removes the DRAFT banner).
2. Fill `mailingAddress` in `assets/config.js`.

## Preview locally
```
python3 -m http.server 8765 --directory babyready-site
```
On localhost, a missing Kit form ID fakes a successful sign-up so the flow can be tested.
